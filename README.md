# Python Speech Recognition Project

This repository contains a Python speech recognition project that focuses on various aspects of audio processing, including recording, converting, and analyzing audio files.

## Project Structure

- **Sentiment_Analysis**: Contains the implementation of sentiment analysis on audio transcripts.
- **Voice Transcript**: Stores the transcript of recorded audio files.
- **__pycache__**: Auto-generated cache files for faster execution of Python scripts.
- **Abhi_new.wav**: An audio file where frame rate modifications were applied.
- **Output.wav**: The output file from a recorded audio session.
- **Triple-H-The-Game.wav**: A theme song in WAV format.
- **api_secrets.py**: Contains the AssemblyAI API key used for speech-to-text conversion.
- **load_mp3.py**: Script for recording voice and converting it into an MP3 file.
- **main.py**: The main script that orchestrates the various functions of the project.
- **mashup.mp3**: An MP3 file created by recording and converting voice.
- **plot_audio.py**: A script for plotting and visualizing audio data.
- **record_audio.py**: Script used for recording audio.
- **wave_example.py**: Example file demonstrating WAV format handling in Python.

## Features

- **Audio Recording**: Capture audio input using `record_audio.py`.
- **Audio Processing**: Perform various operations on audio files, including frame rate modifications and format conversions.
- **Sentiment Analysis**: Analyze the sentiment of transcribed audio using the scripts within the `Sentiment_Analysis` folder.
- **Visualization**: Plot and visualize audio data with `plot_audio.py`.

## Setup Instructions

1. Clone the repository:
    ```bash
    git clone https://github.com/Abhishek3102/Python-Speech-Recognition.git
    ```
2. Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```
3. Run the main scripts using the file names specified.
    
## API Key

Ensure that you have an AssemblyAI API key placed in the `api_secrets.py` file for the speech-to-text functionality.
